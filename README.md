# Food Delivery Website

A responsive Food Delivery Website built using HTML, CSS, and Bootstrap.

## Features

* Responsive Navigation Bar
* Hero Section
* Popular Dishes Section
* Contact Form
* Mobile-Friendly Design
* Bootstrap Components

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5

## Project Structure

Food-delivery-website/
├── index.html
├── style.css
└── README.md

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
